# TEAM Quick Reference — Surgical Hip/Femur Fracture Treatment

**DRGs:** 480 (with MCC) · 481 (with CC) · 482 (without CC/MCC)
**Tier structure:** 3-tier — **both MCCs and CCs move payment**. Document both.
**~Payment delta MCC → CC:** ~$3,000–$4,500 · **CC → base:** ~$2,500–$3,500 (national averages; vary by wage index)
**Post-acute context:** ~38–54% of total episode cost occurs after discharge — the highest of all five TEAM procedures. Documentation gaps in comorbidities also affect SNF/IRF placement appropriateness and post-acute quality benchmarking.

## Top 5 MCCs — Highest Payment Impact

| # | MCC | Why It's Missed | ICD-10 |
|---|-----|-----------------|--------|
| 1 | **Metabolic or Toxic Encephalopathy** | "Delirium" or "confusion" written instead — delirium is a CC, encephalopathy is an MCC | G93.41, G92.9 |
| 2 | **Acute Systolic or Diastolic Heart Failure** | "CHF" or "volume overloaded" — neither is an MCC | I50.21, I50.23, I50.31, I50.33 |
| 3 | **Acute Kidney Injury** | Creatinine elevation documented as lab finding, not AKI diagnosis | N17.0–N17.9 |
| 4 | **Severe Protein-Calorie Malnutrition** | Dietitian documents; physician doesn't — dietitian-only diagnosis is not codeable | E43 |
| 5 | **Sepsis** | "Infection" or "UTI" documented without systemic response language | A41.x + R65.20/R65.21 |

**Also consider:** Acute respiratory failure (J96.01), aspiration pneumonia (J69.0), acute pulmonary edema (J81.0)

## Key HCCs — Target Price Risk Adjustment

SHFFT has 16 HCC risk adjustment variables — the same count as LEJR. The admission H&P is usually the **only** HCC documentation opportunity for this urgent population. There is no pre-op clinic visit.

| HCC | Condition | Documentation Trigger |
|-----|-----------|----------------------|
| 125/126/127 | Dementia (mild / moderate / severe) | Name it and stage it — "confusion" fails; document pre-fracture baseline |
| 224/225/226 | Heart failure (any type/acuity) | Specify systolic vs. diastolic; acute vs. chronic |
| 280 | COPD | Severity, exacerbation status, current medications |
| 253 | Hemiplegia / hemiparesis | Active neurological deficit from prior stroke — not just "history of stroke" |
| 37 | Diabetes with chronic complications | Name the complication — neuropathy, nephropathy, retinopathy |
| 267 | DVT / PE | Acute or chronic; document if on anticoagulation for prior VTE |
| 238 | Specified heart arrhythmias | AF type — paroxysmal, persistent, permanent |

**The admission H&P must do triple work for SHFFT:** establish POA, capture HCCs, and set the comorbidity baseline — all in one document, written urgently. Treat it accordingly.

## Exact Phrasing Examples

**Dementia (most common miss in SHFFT)**
Instead of: *"Patient confused, likely dementia per family."*
Write: *"Moderate Alzheimer's dementia (pre-fracture MMSE 14/30 per family). Behavioral disturbance — agitation present. On donepezil. Baseline cognition confirmed with family prior to fall."*

**Encephalopathy vs. delirium**
Instead of: *"Delirium, multifactorial — pain, sleep deprivation, unfamiliar environment."*
Write: *"Metabolic encephalopathy secondary to hyponatremia (Na 124) and uremia. CAM positive. Treating underlying metabolic etiology."*
> Delirium (F05) = CC. Metabolic encephalopathy (G93.41) = MCC. Name the etiology.

**Heart failure**
Instead of: *"Volume overloaded, CHF — gave Lasix."*
Write: *"Acute on chronic systolic heart failure. IV diuresis initiated, 1.8L net negative. Transitioning to oral Lasix. EF 40% on prior echo."*

**Malnutrition**
Instead of: *"Nutrition consult placed for poor intake."*
Write: *"Severe protein-calorie malnutrition — >10% weight loss over 3 months, significant muscle and fat wasting on exam, albumin 2.1. Meeting ASPEN criteria for severe malnutrition in the setting of acute illness. Enteral nutrition initiated."*

**Hemiplegia**
Instead of: *"History of stroke, left-sided weakness."*
Write: *"Left hemiparesis — residual deficit from prior right MCA stroke. Baseline ambulation with hemi-walker. Deficit present on admission and predates fracture."*

<!-- Section: DischargeChecklist -->
## Discharge Documentation Checklist

**Before signing the discharge summary, confirm:**

- [ ] **Dementia** — if patient has known cognitive impairment: document type (Alzheimer's, vascular, Lewy body), severity (mild/moderate/severe), and behavioral disturbance if present
- [ ] **Encephalopathy** — if acute confusion occurred: distinguish metabolic encephalopathy (MCC) from delirium (CC); name the metabolic etiology
- [ ] **Heart failure** — if diuresis, BNP elevation, or volume management: specify systolic vs. diastolic, acute vs. chronic
- [ ] **AKI** — if creatinine rose at any point: document AKI with stage and likely etiology
- [ ] **Malnutrition** — if weight loss, muscle wasting, low albumin, or reduced intake documented: physician must name severity (mild/moderate/severe)
- [ ] **Sepsis** — if antibiotics started for systemic infection with vital sign changes: document sepsis with source, not just "UTI" or "infection"
- [ ] **Anemia** — if transfusion given: document acute blood loss anemia (D62)
- [ ] **Hemiplegia/hemiparesis** — if prior stroke with residual motor deficit: document the active deficit, not just "history of stroke"
- [ ] **Hyponatremia/hypernatremia** — if Na <135 or >145 required management: document as diagnosis, not lab finding
- [ ] **Diabetes** — specify type and complications; avoid "DM" alone
- [ ] **COPD** — if O₂ requirements increased or respiratory therapy involved: document acute exacerbation
- [ ] **POA status** — all secondary diagnoses should reflect whether present on admission; critical for HAC/pressure injury cases
